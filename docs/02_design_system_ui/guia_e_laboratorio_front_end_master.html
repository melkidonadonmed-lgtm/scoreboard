Como pedir e entender Front-End sem retrabalho

Quando você faz um pedido a um modelo de IA sem especificar os termos corretos de engenharia, ele adota padrões genéricos. Entender a separação em Átomos, Moléculas e Tokens faz com que você receba o código certo na primeira tentativa.

1. Átomos (Atoms) Botões, inputs, ícones SVG
2. Moléculas (Molecules) Busca rápida, card de métrica
3. Organismos (Organisms) Navbar, Drawer, Grid de listas
4. Templates / Páginas Layout fluido A4 / Telas
📱 Layout & CSS

Mobile-First

Desenhar e codificar primeiro para telas pequenas de celular (320px a 480px) e depois expandir progressivamente para telas maiores com min-width.

Por que evita retrabalho:

Se a IA criar para desktop primeiro, a versão de celular quase sempre quebra em largura horizontal e botões pequenos demais para o polegar.

💡 No Prompt peça: "Abordagem Mobile-First rigorosa, alvos de toque mínimos de 48x48px no mobile e zero overflow horizontal."
⚛️ Biblioteca UI

React & Estado Reativo

Divide a tela em blocos isolados com ciclo de vida próprio. Atualiza apenas os nós do DOM que sofreram mutação de dados sem recarregar a página.

Por que evita retrabalho:

Evita que o usuário perca o foco do teclado a cada letra digitada em formulários extensos.

💡 No Prompt peça: "Componentes desacoplados, com nós de formulário isolados para preservar o foco de digitação."
🎨 Estilização

Tailwind CSS & Tokens

Usa classes utilitárias diretas (como p-4 rounded-2xl shadow-xl) calibradas em múltiplos de 4px e 8px, eliminando CSS solto duplicado.

Por que evita retrabalho:

Evita conflitos de especificidade entre arquivos CSS externos e padroniza as cores em uma escala consistente.

💡 No Prompt peça: "Estilize estritamente com classes utilitárias do Tailwind CSS e tokens claros de cores."
⚡ Tooling

Vite & Bundlers Rápidos

O motor moderno que compila código em milissegundos via ES Modules nativos no navegador, substituindo ferramentas lentas como Webpack antigo.

Por que evita retrabalho:

Garante que o projeto inicie instantaneamente em qualquer máquina sem erro de dependências quebradas.

💡 No Prompt peça: "Setup leve com React + Vite + Tailwind CSS para compilação rápida sem pacotes redundantes."
💎 Design Systems

Design Tokens & Relevo 3D

São as constantes visuais (cores de superfície, chanfros de 1px e raios de curvatura) que conferem elegância física à interface.

Por que evita retrabalho:

Impede botões com cores desarmônicas ou sombras que parecem borrões desconexos.

💡 No Prompt peça: "Use chanfro iluminado interno (inset highlight) de 1px e sombra de oclusão curta."
🔌 Protocolos IA

MCP (Model Context Protocol)

O "USB-C dos Agentes": protocolo aberto que conecta IAs a arquivos locais, bancos de dados e APIs sem precisar programar conectores manuais.

Por que evita retrabalho:

Permite que ferramentas como Cursor, Claude Desktop e IDEs executem ações reais de sistema com segurança.

💡 No Prompt peça: "Arquitetura com separação clara de responsabilidades, compatível com MCP tools e schemas JSON estritos."

Showroom Interativo de Botões & Relevos 3D

Toque ou clique nos botões para testar a compressão mecânica (:active) e inspecionar a formulação exata para o seu prompt.

1. Relevo 3D Tátil (Tactile CTA)

Linear / Apple

Chanfro superior iluminado com sombra interna branca (inset 0 1px 1px) e corte escuro na base. Sensação física de hardware de luxo.

Clique para sentir a compressão mecânica
Como pedir no prompt:
"Botão primário 3D tátil com chanfro iluminado interno (inset highlight) e compressão mecânica translateY(1px) no :active."

2. Neumorfismo Fosco (Soft Matte)

Minimalist

Parece esculpido diretamente na superfície, com sombras duplas invertidas em repouso e sem brilho plástico exagerado.

Relevo suave com acabamento acetinado
Como pedir no prompt:
"Estética neumórfica fosca sóbria, acabamento matte sem reflexo artificial, sombras duplas sutis."

3. Glassmorphism (Efeito Vidro)

iOS / VisionOS

Superfície translúcida com desfoque de fundo (backdrop-blur) e borda de 1px simulando vidro lapidado.

Borda fina translúcida + desfoque
Como pedir no prompt:
"Design com Glassmorphism refinado, usando backdrop-blur-md, fundo translúcido e micro-borda de 1px reflexiva."

4. Neo-Brutalismo Moderno

High Impact

Bordas retas de 2px de alto contraste com sombra sólida e dura (sem desfoque), que se desloca fisicamente no clique.

Sombra sólida sem blur com offset rígido
Como pedir no prompt:
"Estilo Neo-Brutalist: bordas pretas de 2px, sombras duras e retas (box-shadow: 4px 4px 0 currentColor) e tipografia bold."

5. Ação Secundária (Ardósia Sóbrio)

Equilíbrio

Serve para ações de apoio (cancelar, voltar, filtros) para não competir com o botão principal da tela.

Fundo neutro que valoriza a ação primária
Como pedir no prompt:
"Botões secundários em cinza neutro ardósia, preservando a hierarquia de atenção do CTA principal."

6. Botão Fantasma (Ghost Action)

Navegação

Invisível em repouso; acende suavemente com uma cápsula de cor ao passar o mouse ou receber foco pelo teclado.

Ideal para linhas de tabelas e menus limpos
Como pedir no prompt:
"Use botões variantes Ghost (sem borda no estado neutro, com hover:bg-cyan-500/10) em ações repetitivas de lista."
