Dicionário de Engenharia Front-End

Compreenda os termos fundamentais para orientar IAs sem ambiguidades e eliminar refações.

📱 Layout & CSS

Mobile-First

Projetar a experiência e o CSS primeiro para telas compactas (320px a 480px) e expandir progressivamente com min-width.

💡 No Prompt: "Desenvolva com abordagem Mobile-First estrita, alvos de toque mínimos de 48x48px e zero overflow horizontal."
⚛️ Reatividade

React & Estado Desacoplado

Divide a tela em blocos autônomos. Preserva nós do formulário para evitar que a cada letra digitada o usuário perca o foco do cursor.

💡 No Prompt: "Componentes desacoplados, com nós de formulário isolados para preservar o foco de digitação."
🎨 Estilização

Tailwind CSS & Tokens

Utiliza classes utilitárias diretas em múltiplos de 4px e 8px, padronizando margens e cores em uma escala visual harmônica.

💡 No Prompt: "Estilize estritamente com classes utilitárias do Tailwind CSS e tokens claros de cores e elevação."
⚡ Tooling

Vite & Bundlers Rápidos

Motor moderno que compila arquivos via ES Modules nativos no navegador, inicializando projetos em milissegundos.

💡 No Prompt: "Setup leve com React + Vite + Tailwind CSS para compilação rápida sem pacotes redundantes."
💎 Design Tokens

Design Tokens & Relevo 3D

Constantes visuais (superfícies, chanfros de 1px e raios) que dão elegância física tátil aos componentes sem aspecto plano.

💡 No Prompt: "Use chanfro iluminado interno (inset highlight) de 1px e sombra de oclusão curta."
🔌 Protocolos IA

MCP (Model Context Protocol)

O "USB-C dos Agentes": protocolo aberto que conecta IAs a arquivos locais, bancos de dados e APIs sem código manual descartável.

💡 No Prompt: "Arquitetura com separação clara de responsabilidades, compatível com MCP tools e schemas JSON estritos."

Arquitetura de Menus: Celular vs. Computador

📱 No Celular (Mobile < 768px)

O menu superior no topo da tela exige que o usuário use as duas mãos ou estique o polegar, gerando desconforto. A solução obrigatória é a Bottom Navigation Bar fixada na base, respeitando a área de toque mínima de 48×48px.

💻 No Computador (Desktop > 1024px)

A barra inferior desaparece e dá lugar a uma Sidebar Persistente ou abas horizontais no topo com suporte a atalhos de teclado (Tab, Esc).
